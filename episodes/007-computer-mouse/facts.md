# Facts — What's inside a computer mouse? (ep. 7)

| Claim | Source |
|---|---|
| Mouse buttons press microswitches: a thin metal leaf is pushed onto a contact, closing a circuit | https://www.techspot.com/article/2181-anatomy-mouse/ |
| The scroll wheel drives a rotary encoder; notches come from a metal piece bumping over teeth; signal tells the chip which way/how fast | https://www.techspot.com/article/2181-anatomy-mouse/ |
| Optical mice light the surface with an LED at a grazing angle so texture casts shadows | https://en.wikipedia.org/wiki/Optical_mouse |
| Red is the most common LED colour (cheap, silicon sensors sensitive to red) | https://en.wikipedia.org/wiki/Optical_mouse ; https://www.techspot.com/article/2181-anatomy-mouse/ |
| A tiny image sensor captures over a thousand images per second (ADNS-2610: 1,500 frames/s) | https://en.wikipedia.org/wiki/Optical_mouse ; https://fab.cba.mit.edu/classes/863.09/people/labrune/files/camera/ADNS2610.pdf |
| A chip compares successive images (cross-correlation) to compute movement | https://en.wikipedia.org/wiki/Optical_mouse ; ADNS-2610 datasheet |
| Standard optical mice struggle on clear glass / mirrors (no texture to track) | https://en.wikipedia.org/wiki/Optical_mouse ; https://www.lenovo.com/sg/en/glossary/optical-mouse/ |
| Each frame can be just 18×18 pixels (ADNS-2610: 324 pixels per frame = 18×18) | https://fab.cba.mit.edu/classes/863.09/people/labrune/files/camera/ADNS2610.pdf |
| First mouse: Douglas Engelbart, SRI, ~1964, wooden shell, two metal wheels | https://www.computinghistory.org.uk/det/5403/Douglas-Engelbart-invents-the-mouse/ |
| Named "mouse" because it looked like a mouse with a tail (the cord) | https://www.computinghistory.org.uk/det/5403/Douglas-Engelbart-invents-the-mouse/ |
